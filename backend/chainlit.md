# GEFIN Agent

Agentic Analytics · Contas a Receber · Protótipo local com governança e linhagem

**GEFIN Agent** é um protótipo de sistema **agentic** para analytics financeiro.

- Linguagem natural → SQL governado
- Apenas views semânticas (whitelist)
- Linhagem visível em toda resposta
- LLM configurável: Claude · OpenAI · Ollama

Escolha um assistente (Contas a Receber ou Fabric) para começar.
